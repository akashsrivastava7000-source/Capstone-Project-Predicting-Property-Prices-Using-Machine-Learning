# Capstone-Project-Predicting-Property-Prices-Using-Machine-Learning
Capstone Project is a Machine Learning project for predicting property prices.

🏠 Project: Predicting Property Prices
Dataset: Property_data
Records: 1,460 properties
Original Features: 81 columns
Target Variable: PropPrice
Objective: Build a machine learning model that can predict the price of a property based on its characteristics.
Main steps i have completed
Data Understanding – understood the dataset, columns, target variable, and data types.
Data Cleaning – handled missing values and checked for duplicates.
Categorical Feature Classification – separated ordinal and nominal variables.
Encoding – applied ordinal encoding and one-hot encoding.
EDA – analyzed relationships between features and property prices.
Feature Selection & Engineering – examined important features and correlations.
Scaling – standardized numerical features.
PCA – reduced the dimensionality while retaining important information.
Model Building – tested:
Linear Regression
Decision Tree
Random Forest
Model Evaluation – compared models using MAE and R².
🏆 current best model

Random Forest

MAE: ≈ 19,334
R² Score: ≈ 0.856

This means your Random Forest model explains approximately 85.6% of the variation in property prices, making it the best-performing model among the models i tested.

In one sentence:

Capstone project uses data preprocessing, EDA, encoding, scaling, PCA, and machine learning algorithms to develop a Random Forest model capable of predicting property prices with an R² score of approximately 85.6%.
